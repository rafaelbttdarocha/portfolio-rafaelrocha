# Portfólio — Rafael Rocha

Portfólio de **UX/UI Designer Pleno**, feito em HTML, CSS e JavaScript puro, sem frameworks. Responsivo, com tema claro/escuro e páginas de estudo de caso.

## Estrutura

```
index.html          Página principal (sobre, projetos, experiência, skills, contato)
nutriflow.html      Estudo de caso: NutriFlow
mercado-livre.html  Estudo de caso: análise heurística do Mercado Livre
assets/
  case.css          Estilos das páginas de caso
  favicon.svg       Ícone (adapta ao tema do navegador)
  *.jpg             Foto, capas dos projetos
  rafael-rocha-cv.pdf  Currículo
  proj/             Imagens dos estudos de caso
```

## Rodar localmente

Basta abrir `index.html` no navegador. Para servir com um servidor estático:

```bash
python -m http.server
```
